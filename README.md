Token Radar ranks every pre-token protocol in the DefiLlama snapshot by its implied launch value — calibrated on live-token comparables in the same category — and gives each one a concrete farm plan with cost and time per step. The board covers the full 40-protocol watchlist plus 158 early finds below the floor; bridged, wrapped and staked products of tokens that already trade are left out on purpose. The dashboard is a static page (no network): search, filter by category and chain, sort, and a detail view per protocol with its model breakdown and farm plan.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input ../input/snapshot.json
```
